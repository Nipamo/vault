# vault
Stores passwords with usernames for specific websites or just tags

Vault ist eine lokale C++ CLI Anwendung zur Verwaltung von Zugangsdaten. 
Die Daten werden lokal in einer .json gespeichert.
Der Benutzer kann Einträge erstellen, anzeigen, bearbeiten, löschen und suchen.

Benutzung:
1. Start über ./build/vault
2. Master Password: 0000
